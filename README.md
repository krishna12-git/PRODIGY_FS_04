# Circlo Social

A responsive social media front-end with a warm, original visual style. Users can browse a feed, like and comment on posts, follow creators, edit a profile, view notifications, and publish text, image, or video posts.

## Live Demo

[Open Circlo Social](https://circlo-social.krishyadav7856.chatgpt.site)

## Features

- Responsive desktop and mobile layouts
- Stories, home feed, and following feed
- Create-post modal with image/video previews and tags
- Like, comment, save, and share interactions
- Follow/unfollow suggestions
- Profile editing and notifications
- Custom social photography sprite included in `public/assets`

## Run Locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local address printed in your terminal, usually `http://localhost:5173`.

## Build

```bash
npm run build
```

## Technology

- React 19 and TypeScript
- Vinext and Vite
- Tailwind CSS 4
- Cloudflare-compatible production output

## Demo Note

This is a front-end demonstration. New posts, profile edits, comments, likes, and follows are stored only in the current browser session and reset when the page is refreshed. Uploaded files are previewed locally and are not sent to a server.
